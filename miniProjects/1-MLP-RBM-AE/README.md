# Project 1 — MLP, RBM and Autoencoder

This mini-project uses daily bakery revenue data to demonstrate three neural-network approaches:

1. **MLP:** predict revenue for a product group using previous sales and calendar-related features.
2. **RBM:** discover hidden patterns in 14-day windows of sales.
3. **Autoencoder:** compress and reconstruct 14-day sales windows, then inspect reconstruction errors.
