# Bakery Sales Guide

This folder contains the guided notebook for the MLP, RBM and Autoencoder bakery-sales mini-project.

## Files

| File | Purpose |
|---|---|
| proj1-g.ipynb | Guided notebook and explanations |
| train.csv | Main bakery sales dataset (required) |
| wetter.csv | Weather features (optional) |
| kiwo.csv | Kieler Woche event dates (optional) |

## Running the notebook

1. Download or clone this folder.
2. Keep the notebook and CSV files together.
3. Open proj1-g.ipynb in Jupyter Notebook or JupyterLab.
4. Install the libraries imported by the notebook if they are not already installed.
5. Run the notebook from top to bottom.

The notebook can run without the two optional CSV files. When available, they provide additional weather and event features for the MLP section.
